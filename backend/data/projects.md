# Project Portfolio

## SentinelPulse
An AI-powered social media trend monitor.
**Tech Stack:** FastAPI, React.js, PostgreSQL.
**Description:** Monitors trends in real-time, built with a robust backend architecture for fast data ingestion and processing.

## EchoPath
An AR-powered audio navigation system designed for visually impaired users.
**Description:** Uses augmented reality and spatial audio cues to guide users through physical environments safely.

## Aura
An automated real-time UI audit tool.
**Description:** Evaluates user interfaces dynamically to ensure accessibility, design consistency, and usability standards are met.

## SentinelExam
A web-based proctoring system.
**Description:** Features suspicion scoring and tab-switch monitoring to ensure academic integrity during online assessments.
